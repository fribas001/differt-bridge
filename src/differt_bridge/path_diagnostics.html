How paths are paired

Paths must have the same ordered interaction sequence, with every corresponding vertex within __TOLERANCE__ mm. Matching maximizes the number of paired paths. Multiple possible candidates are labeled ambiguous; their metric deltas remain unavailable. Gain and delay do not influence pairing. Backend object IDs and path indices are not shared identities.

Only links with matched captured inputs and verified geometry are compared. “Only” means absent from the other complete captured result at this tolerance. It does not identify a solver error. A top-path selection, capture limit, or missing data produces a subset label instead. Coordinates and metrics read from Blender's saved point attributes have float32 precision; phase differences are wrapped to [−π, π).
